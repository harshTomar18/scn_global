# SCN Global Pvt. Ltd. — Corporate Web Application

High-contrast, luxury web application for **SCN Global Pvt. Ltd.** featuring strategic staffing, 100% tech-enabled payroll outsourcing, executive recruitment, HR statutory compliance (21+ Labour Acts), industrial staffing, and project hiring services.

## Tech Stack & Design System
- **Framework**: React + Vite
- **Styling**: Vanilla CSS (Super Travel Luxury Design System `#fdf8f3`, `#f5f0eb`, `#e4a4bd`, `#262626`, League Spartan Font)
- **Icons**: Lucide React
- **Routing**: React Router DOM

## Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```
